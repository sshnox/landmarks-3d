# Dependencies

- [Three.js 0.128.0](https://cdn.jsdelivr.net/npm/three@0.128.0/build/three.min.js): graphics library used by the viewer.
- [Three.js upstream and MIT license](https://github.com/mrdoob/three.js).

All landmark geometry is generated in the app. No third-party 3D model assets are bundled.
